顺序栈实现 README
项目名称
基于 C++ 的顺序栈（Stack）实现
项目简介
本项目使用 C++ 语言 实现顺序存储结构的栈，基于数组和指针完成栈的所有基础操作。
代码包含栈的初始化、入栈、出栈、取栈顶、遍历、清空、销毁、判空、判满等功能，严格遵循栈 先进后出（FILO） 的特性。
代码文件说明
本项目包含两个核心文件：
Stack.h —— 栈结构体定义、函数声明、宏定义
Stack.cpp —— 栈所有功能的具体实现（即你提供的代码）
功能实现清单
你提供的代码实现了以下 10 个栈操作函数：
IniStack —— 初始化栈
为栈分配连续内存空间，设置栈顶、栈底指针，初始化栈容量。
Push —— 入栈操作
判断栈是否已满，未满则将元素插入栈顶，并移动栈顶指针。
Pop —— 出栈操作
判断栈是否为空，非空则取出栈顶元素，输出被删除元素值。
GetTop —— 获取栈顶元素
不修改栈结构，仅读取并返回当前栈顶元素。
TopTraverse —— 倒序遍历栈
从栈顶向栈底遍历输出所有元素。
BaseTraverse —— 正序遍历栈
从栈底向栈顶遍历输出所有元素。
ClearStack —— 清空栈
仅重置栈顶指针，不释放内存，栈可继续使用。
DestroyStack —— 销毁栈
释放栈占用的内存，将指针置空，彻底销毁栈结构。
StackEmpty —— 判断栈是否为空
返回布尔值，表示栈当前是否为空。
StackFull —— 判断栈是否已满
检查栈空间是否用尽，并输出提示信息。
